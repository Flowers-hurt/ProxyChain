# Security Policy

ProxyChain is a static, browser-only tool: no backend, no analytics, and no
network calls at runtime. Proxy credentials and configs never leave the
browser. Anything that violates that promise is a security bug.

## Reporting a vulnerability

Please report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/Flowers-hurt/ProxyChain/security/advisories/new)
rather than opening a public issue. Include steps to reproduce and the impact
you see. You should get a response within a week.
